# Water Veil 需求文档

## 1. Overview

一件以玩家头像为内容输入的全屏水面肖像：单指划过即可搅动倒影，松手后水面在
1.25 秒内重新平静并短暂完成一次“倒影封存”。

## 2. Visual Design

完整保留原作蓝绿色水面、十层表面噪声、照明高光和边缘消隐。产品层只增加上方
大标题、底部身份署名、Google Material 幽灵手指以及居中结算字样。目标视口为
390×844 与 320×568；视觉规范详见 `doc/visual.md`。

## 3. Game Mechanics

- 初始化：原作参数 `blueish=.6`、`scale=7`、`illumination=.15`、
  `surfaceDistortion=.07`、`waterDistortion=.03`。
- 更新循环：每帧写入时间与触点强度，触点强度以 0.07 插值追随目标值。
- 特殊机制：触点周围生成频率 54、空间衰减 8、最大位移 0.018 的环形水波。
- 身份输入：`avatar_url` 调试值 → 玩家 `head_url` → 用户提供的 AlterU 默认头像；
  `?baseline=1` 使用原作照片。
- 结算：松手后 1.25 秒且水波强度低于 0.04 时显示 1.5 秒封存结果。

## 4. Controls

- Pointer / Touch：单指按下并拖动水面，实时移动扰动中心；松手后水波衰减。
- Mouse：与触屏相同。
- 引导：首次加载 0.9 秒后幽灵手指执行一次真实水波演示；用户操作立即取消。

## 5. Win / Lose Conditions

没有失败条件。每次完成“按下—拖动—松手—水面平静”即构成一轮闭环，结算显示
玩家用户名与“倒影已平静”；玩家可立即继续下一轮。

## 6. Sound Effects

首版保持无声，避免自动播放限制和持续环境音干扰信息流；所有反馈由水波位移、
高光变化、幽灵手指和结算淡入完成。
