# Water Veil 视觉 QA

## 检查范围

- 390×844 产品模式：头像内容、标题、身份署名、幽灵手指、真实拖动与结算。
- 320×568 产品模式：低矮屏标题缩放、长用户名截断、底部安全区。
- 390×844 `?baseline=1`：原作照片与原始 shader 参数。
- 头像失败：无效公网头像自动回退 AlterU 默认头像，不进入错误页。

## 首轮问题与修复

1. 公网头像加载失败会留下空白水面；改为保留玩家姓名并回退 AlterU 默认头像。
2. 390px 下长用户名可能挤压 `REFLECTION OF`；收紧字距并把第三列限制为
   `min(42vw, 250px)`。

## 匹配复验

- 两项修复均在相同 URL 与相同视口复验。
- 320×568 的标题、主体与署名未遮挡；长名以省略号截断。
- Pointer 拖动后水波立即增强；松手 1.25 秒后 `wv-sealed--show` 可见。
- 控制台无未处理错误；头像失败只产生预期降级警告。

结论：P0 / P1 为 0，可进入发布。
